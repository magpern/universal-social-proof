Establish a loadable, namespaced, WooCommerce-aware, HPOS-declared, testable, CI-protected plugin at **`0.0.0`** that is **functionally inert** as a social-proof product.

- Plugin identity, Composer PSR-4, bootstrap
- WooCommerce dependency handling (graceful without WC)
- HPOS compatibility declaration
- Minimal lifecycle (no feature schema)

- M0 exclusion / policy guards in CI
- Track `composer.lock` (align with siblings; remove from `.gitignore`)

## 7. Bootstrap design

**Main file responsibilities**

1. WordPress plugin headers (identity, Requires PHP/WP, Requires Plugins: woocommerce, WC headers).
2. `defined( 'ABSPATH' ) || exit`.
3. `USP_VERSION`, `USP_PLUGIN_FILE`, `USP_PLUGIN_DIR`.
4. PHP `< 8.1` → admin error notice + `return` (file-drop guard; UGC/UMC).
5. Require Composer autoload when readable; if missing → admin notice for capable users + `return`.
6. `before_woocommerce_init` → `FeaturesUtil::declare_compatibility( 'custom_order_tables', USP_PLUGIN_FILE, true )` only when class exists. (HPOS only in M0 — no cart/checkout blocks claim required for order-table honesty; optional `cart_checkout_blocks` **omitted** because USP will touch orders later and should not over-claim storefront block compatibility without evidence.)
7. `plugins_loaded` → if WooCommerce inactive: restrained admin notice (`manage_woocommerce` / `activate_plugins` capable users); if active and `Plugin` class exists: `Plugin::init()`.

**`Plugin`**

- Final class, `declare(strict_types=1)`.
- Idempotent `init()` guarded by static flag + `WooCommerceGate::is_active()`.
- M0 body: no feature registrations (no REST, capture, admin menu, cron).
- `reset_for_tests()` seam like UPR.

**`WooCommerceGate`**

- `is_active(): bool` via `class_exists( 'WooCommerce' )`.

**Activation / deactivation**

- **Omit** hooks in M0 — no schema, options, or cron to create; nothing to tear down. Deactivation must never delete future data; uninstall speculative deletion deferred.

## 11. Testing strategy

**Unit** (`phpunit.xml.dist`, no WordPress):

- Autoload / class existence
- Version constant consistency vs plugin header (parse header string)
- `WooCommerceGate` behaviour with stubbed `class_exists` seam **or** pure constant/header tests without loading main file fully
- Source-policy helpers if kept pure PHP

Prefer loading Composer autoload + defining minimal stubs; avoid bloated UPR-style stub universe.

**Integration** (`phpunit-integration.xml.dist` + `tests/bin/install-wp.sh`):

- Plugin file loads under WP + WC
- `Plugin::init()` succeeds when WC present
- HPOS compatibility declared
- No `{prefix}usp_events` table
- No `usp/` or `universal-social-proof/v1` REST routes registered by USP
- No frontend USP scripts/styles enqueued from foundation

**WC-absent:** Covered by unit/source behaviour + main-file structure (notice path); full WP without WC is optional if install script always loads WC — document as unit/policy coverage.

## 15. Explicit M1+ exclusions

Do **not** implement: `usp_events`, migrator, `source_order_id` / `source_item_id` / `public_id`, UUID generation, `occurred_at` resolver characterization, capture hooks, refunds, terminal suppress implementation, selection, REST notifications, FE toaster/JS/CSS, templates/tokens, UGC adapter, privacy exporter/eraser implementation, settings UI, fake events, region/city.

ADR-0004 remains Requires M1 evidence — do not freeze resolver in M0.

CI `check.sh` will fail the build if forbidden M1+ symbols/paths appear under `src/` or the main file.

## 18. Implementation sequence

1. Commit this plan alone (`docs: freeze M0 foundation plan`).
2. Scaffold Composer, main file, `src/`, LICENSE, gitignore lockfile fix, README/CHANGELOG/CONTRIBUTING.
3. Add PHPCS + unit/integration tests + `install-wp.sh` + `scripts/ci/check.sh`.
4. Add GitHub Actions CI.
5. Run local validation (Docker PHP/Composer if host PHP absent).
6. Write `M0-FOUNDATION-CLOSURE.md`; commit closure.
7. Push `feature/m0-foundation`; open PR to `main`; observe CI; fix if needed.
8. **Stop** — do not merge; do not start M1; do not tag `v0.0.0`.
